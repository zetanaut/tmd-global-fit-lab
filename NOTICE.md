# Provenance, access and redistribution

This repository contains a new portable execution/coordination layer and a
computational port of the owner's existing Nested-FiLM model and signed grouped
evaluator. Scientific source and metric identities remain attributed to the
historical analysis. Original computational source snapshots are preserved in
the numerical input release with byte hashes. Transport identities are new and
are never presented as original source identities.

No blanket open-source license or public redistribution right has been asserted
for the historical code, experimental inputs, PDFs/FFs, compiled coefficients or
other third-party assets. Keep the repository and releases private for authorized
research collaborators until the owner reviews provenance, licenses and any
experimental-data access terms. No original home directory, private coordination
transcript, credential file or full workspace history is packaged.

Prepared scripts do not reconstruct experimental measurements, regenerate
perturbative inputs, or confer permission to change the scientific prescription.
Public scientific publication and a production extraction require separate review.
